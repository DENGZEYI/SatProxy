# Introduction to SatProxy
SatProxy is a novel proxy design that improves throughput in networks with high packet loss, such as Low Earth Orbit (LEO) satellite networks. 

SatProxy is an modification of the widely used VPN, WireGuard (Go implementation).

Compiling and running SatProxy is the same as WireGuard-Go. Please refer to the WireGuard-Go documentation for details (https://github.com/WireGuard/wireguard-go).
